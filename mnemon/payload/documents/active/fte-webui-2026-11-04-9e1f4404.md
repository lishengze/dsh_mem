# FTE 控制台 WebUI：亮/暗主题与全站自适应（2026-11-04）

范围：`gt_trunk/DYS-FRAMEWORK/fte/test_all/webui/static` 前端的主题切换与响应式改版，
以及随之修复的 canvas 折线图适配问题。控制台的服务端结构、归档与解析见同一项目的
既有文档 `3477111d-5bb4-4540-a1db-1b7e6b1132ed`（本机部署与三类静默失败修复）。
仓库内同步文档：`webui/MANUAL.md` §5.9「主题与自适应」+ 已知限制 9a、

## 1. 主题系统（交付形态）

| 维度 | 方案 |
|---|---|
| 入口 | 每页顶栏右侧 `🌙 暗色 / ☀ 亮色` 按钮（`#themeBtn`，`themebtn`） |
| 存储 | 优先 `localStorage`；未设置时跟随系统 `prefers-color-scheme` |
| 深链 | `?theme=dark` / `?theme=light` 强制指定，**不写 localStorage**（便于分享与截图对比） |
| 实现 | `theme.js` 在 `<head>` 中同步执行，给根节点设 `data-theme` |
| 样式 | `style.css` 全量改为 CSS 变量，约 40 个语义 token，亮/暗各一份变量表 |
| 覆盖 | 顶栏、面板、按钮五态（灰/蓝/红/绿/闪烁）、步骤与子步骤、日志、表格、案例树、diff、折线图、弹窗、toast |
| canvas | 不继承 CSS：`perf.js` 从 CSS 变量取色，并订阅 `fte-theme-change` 事件重绘 |

关键理由：`theme.js` 必须是 `<head>` 内同步脚本（先于 CSS 绘制设属性），否则暗色下会有一帧白闪；
所有页面模板都要在 `<head>` 引入 `/static/theme.js`（本次改动为 4 个页面各 +2 行）。
脚本/样式回退：`perf.js` 的取色用 `cssVar(name, fallback)`，变量缺失时退回原硬编码色，避免旧缓存下图表变黑。

## 2. 自适应布局（断点与容器策略）

| 组件 | 改前 | 改后 |
|---|---|---|
| 主网格 | `1fr 1fr` + `max-width:1500px` | `auto-fit` / `minmax(min(100%,430px),1fr)` + `grid-auto-flow: dense` |
| 功能/代码管理页侧栏 | 固定 300/340px | `clamp(220px,20vw,340px)`；≤1080px 切单列 |
| 性能页表格 | 窄屏「场景」列竖排折行 | `min-width:640px` + 容器横向滚动 + 单元格 `nowrap` |
| 本地日志 | 固定 300px 高 | `clamp(220px,32vh,520px)` |
| 折线图 | `canvas width=1180` 写死 | 按容器宽 + `devicePixelRatio` 重算，resize 防抖重绘，窄图 X 轴标签抽稀 |
| 顶栏 | 单行易挤压 | `flex-wrap`；≤760px 收紧字号与间距 |

语义：宽屏要「自动补齐列数」而不是留白；窄屏要「单列堆叠 + 表格横滚」而不是压缩列宽导致折行。

## 3. 四个真实踩到的坑（可复用）

1. **1920 宽右侧大片空白**：`auto-fit` 只按已有条目排满可见行，缺 `dense` 回填 → 加 `grid-auto-flow: dense` 才补满。
2. **表格窄屏竖排折行**：列宽被压缩到单字宽度 → 给表格 `min-width` + 父容器 `overflow-x:auto`，并给单元格 `nowrap`。
3. **图表点击命中偏移**：canvas 绘制按 dpr 放大，命中判定若用 CSS 像素须换算 `x * (canvas.width / rect.width)`；同时 `padL/padR` 必须与绘制函数一致（本次为 66/18）。
4. **canvas 不吃主题变量**：改了 `data-theme` 后折线图仍是旧配色 → 统一派发 `fte-theme-change` 事件，绘图函数重读 `cssVar()` 后整幅重绘。

## 4. 验证手法

- **逻辑单测**：node + 极简 DOM 垫片直接跑 `theme.js`，10 条断言全过 —— 首帧跟随系统、toggle 写存储、`set()` 生效、按钮已绑定、`?theme=` 覆盖且不写存储。
- **视觉验证**：headless Chromium 截图 12 张，覆盖 4 个页面 × 亮/暗 × 1920/1600/1400/1100/900/760，逐张核对配色切换、无溢出、窄屏单列、表格横滚、图表随宽度重排。
  截图对比用 `md5sum` 判定「布局是否真的变了」（相同 md5 说明该修复未生效）。
- **静态检查**：`node --check` 过 5 个 js（theme/perf/app/func/vcs）+ 括号平衡计数；`curl -I`/GET 校验 `/static/theme.js`、`/static/style.css` 均 200 且页面含 `themeBtn`。
- 服务端对本机 `HEAD` 请求返回 501（`FTEConsole/0.1` 只实现 GET），做缓存头探测时要用 GET。
