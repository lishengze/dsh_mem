# 四台测试机统一免密登录落地与验证（2026-11-28）

目标：把本机公钥下发到 49 / 121 / 122 / 42 四台测试机的 root，统一走 `ssh -p 2201 root@<ip>` 免密登录。
连接方式、2201 打通的根因与 `firewall-cmd --reload` 覆盖 runtime 的坑，见既有文档 `b532aca2-6778-4e3a-b1e2-5929b62fb66d`（本文只记「下发 + 验证」这一段）。

## 1. 目标矩阵与实测档案

| 主机 | 地址 | 端口 | 实测档案 |
|---|---|:-:|---|
| 49 | `10.189.111.49` | 2201 | `localhost.localdomain`，aarch64，256 核 |
| 121 | `10.189.65.121` | 2201 | `lingqu01`，aarch64，344 核 |
| 122 | `10.189.65.122` | 2201 | `lingqu02`，aarch64，160 核 |
| 42 | `10.189.111.42` | 2201 | `localhost.localdomain`，x86_64，80 核（20C×2 HT，CentOS 8） |

本机公钥：`~/.ssh/id_ed25519.pub`，追加时统一加注释后缀 `lsz-dev-20261128`，便于日后按串精确吊销。
42 在 2201 放通并追加公钥后**已可本机直连**，不再必须经 49 跳板（跳板仍可用）。

## 2. 下发步骤（幂等，可重复执行）

1. 逐台记录基线：`authorized_keys` 行数/字节数、`mode/owner`、`.ssh` 目录权限。
2. 备份：`cp -a /root/.ssh/authorized_keys /root/.ssh/authorized_keys.bak_lsz-dev-20261128`。
3. 去重后追加，**用 stdin 直写**：
   ```bash
   ssh -p 2201 root@<ip> 'cat >> /root/.ssh/authorized_keys' < ~/.ssh/id_ed25519.pub
   ```
4. 权限显式收紧：`install -d -m 700 /root/.ssh` → `chmod 600 /root/.ssh/authorized_keys` → 属主 `root:root`。

## 3. 验证（只看公钥，禁密码回落）

```bash
ssh -o BatchMode=yes -o PreferredAuthentications=publickey -p 2201 root@<ip> 'hostname'
```

必须用 `BatchMode=yes`：否则 ssh 可能靠密码或 gssapi 成功，掩盖公钥没生效的事实。
本次四台全部返回预期主机名：`localhost.localdomain / lingqu01 / lingqu02 / localhost.localdomain`。

## 4. 踩坑与判据

1. **`echo "$KEY" >> authorized_keys` 会只写进一个换行**：42 上就出现「文件只多 1 字节、key 数不变」。判据：追加前后比对 `wc -l` 与 `wc -c`，且用 stdin 重定向（`cat >> file`）代替 `echo >>`。
2. **`authorized_keys` 必须 600、`.ssh` 700、属主 root**。StrictModes 默认开启，权限过宽会让 sshd **静默拒绝**公钥（日志里不明显）。本条为使用方明确要求。
3. **读 `/root/.ssh/authorized_keys` 必须提权**：以普通用户执行 `grep` 会报「权限不够」，容易误判成「文件不存在/为空」。同一条命令在 root 下重跑即正常（`ls -lZ` 可见 SELinux 上下文 `ssh_home_t`，无需额外打标）。
4. **追加成功的判据是三件一起看**：`mine=1`（本机公钥命中一次、无重复）、`mode=600 owner=root:root`、`dirmode=700`；再叠加第 3 节的 BatchMode 登录才算通过。
5. 42 的 `22` 端口在放通 2201 后对本机**仍 closed**（变更前也 closed，22 只对同网段开放）——不要把这一条当作回退。

## 5. 回滚

```bash
# 撤销本机公钥（四台各自执行，经任一可用跳板亦可）
sed -i '/lsz-dev-20261128/d' /root/.ssh/authorized_keys
# 或直接还原备份
cp -a /root/.ssh/authorized_keys.bak_lsz-dev-20261128 /root/.ssh/authorized_keys && chmod 600 /root/.ssh/authorized_keys
```
