## 1. 老系统语义（本轮恢复的行为）

`estimated` / `g_*` 兜底键 `g_estimated` 是"设置校验位"：

| 取值 | 语义 | 行为 |
|---|---|---|
| `'0'` | 检查 | 连通性检查：只验链路/权限，**不执行业务必填校验、不落库**，直接返回成功，日志 `Connectivity check passed` |
| 其它 / 缺省 | 运行 | 完整必填校验 + 业务处理 + 落库 |

改造前该提前返回分支被注释掉，导致 `'0'` 也照常落库，与老系统不一致。修法：在 `otcsrc/lbm/lbm_otc_param/src/processors/per_cust_risk_ctrl_set_processor_411833.cpp` 的 `ExecuteBusiness()` 开头恢复
`if (m_cEstimated == '0') { LogInfo(...); SetLbmSucc("Connectivity check passed"); return 0; }`，并保留原注释说明两态语义。

**必读坑**：业务用例必须显式传 `estimated='1'`（或 `g_estimated='1'`）走运行态，否则 `'0'`/缺省组合下断言会静默落空；验证"不落库"要用**另一个查询接口反查**（本案用 411834 查同 custid+fundid，0 行即证明未写库）。
