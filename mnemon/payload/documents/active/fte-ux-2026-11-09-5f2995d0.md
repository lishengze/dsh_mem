# FTE 测试控制台查看器 UX 精修：贴边、可折叠目录树与可拖拽宽度（2026-11-09）

范围：`gt_trunk/DYS-FRAMEWORK/fte/test_all/webui` 的 `/logs`（日志查看）与 `/data`（数据与配置）两个查看页。
本记录补齐前一阶段「浏览器内点击尚未实测」的缺口，并记录三项布局改造的根因与可复用做法。
衔接既有文档：`2c2b5ebe-117e-4de3-8a17-52f60834a5fe`（/logs、/data 与单案例运行的来源）、`97e362f5-6c02-45e0-9835-a66136108bcb`（/code 页与 `.splitter` 拖拽原型的出处）。

  正则 OFF→ON `[info]` 1392→27058（字面量 vs 字符类），ON→OFF `\d{4}-\d{2}` 1402→0。

## 验证中发现并修复的两个真实缺陷

1. **bin 转出的 xml 写到宿主不可写目录**：run 目录由容器内 root 创建，宿主控制台（uid 1000）写入报 `Permission denied`。
   改为「同目录优先，不可写则回退 `~/.cache/fte_console/bin_xml/<market>/`」，并在提示中说明落点。
2. **回退后每次点 bin 都重新生成**：复用判断只比较同目录 xml 的 mtime。
   修法是让回退目录也参与 mtime 比较，二次点击即复用（`created=False`）。

## 布局三项改造

### 1. 左栏不贴边（根因最隐蔽）

全局样式 `main{ max-width:1800px; margin:0 auto; padding:...; display:grid }` 同时命中了查看器页的 `<main class="layout three-left">`，
把整个查看器推到页面中间并加了内边距（实测 `aside.nav` 的 left = 15.25px）。
修复是追加更高优先级的覆盖规则，而不是改全局 `main`（首页面板栅格仍要它）：

```css
main.layout.three-left {
  width: 100%; max-width: none; margin: 0; padding: 0; gap: 0;
  grid-template-columns: var(--tree-w, 340px) 8px 1fr;
}
```

### 2. 目录树分层不能折叠

原树是「分组标题 + 平铺叶子」，没有子容器也就没有折叠状态。改为每组渲染 `节点(.node.grp) + .tree-children` 容器，
点节点切换 `hidden`，三角 `▾` 用 `rotate(-90deg)` 变 `▶`。日志页按组件分组折叠；数据页两级折叠（市场 → 数据/配置）。

折叠正确性用**可见叶子数**判断，而不是看 class：全部展开 131 → 折叠「上海」70 → 再折叠「数据」类别 76 → 还原 131；
日志页单组折叠后可见叶子 17。

### 3. 左栏宽度可拖拽（复用 /code 页机制，不重造）

复用 `static/code.js` 已验证的 splitter 模式，两个查看页的 `<main class="layout three-left">` 改为三列栅格：

```css
grid-template-columns: var(--tree-w, 340px) 8px 1fr;   /* 左栏 | 8px 拖拽条 | 右栏自适应 */
```

| 项 | 行为 |
|---|---|
| 拖动 | 实时写 `--tree-w`，右侧 `1fr` 自动占满剩余（无需 JS 算右栏宽度） |
| 下限 / 上限 | 180px / 窗口宽 − 340px（保证右栏 ≥ 340px） |
| 双击拖拽条 | 复位 340px |
| 持久化 | `localStorage['viewer-tree-w']`，日志页与数据页共用同一 key |
| 窄屏 | `@media(max-width:900px)` 限制 `min(--tree-w, 46vw)` |

实测：初始 340/924 → 拖到 520/744 → 触底 180 → 双击回 340 → 设 460 刷新后仍 460，切到数据页同步 460。

### 顺带修掉的显示问题

文件名折行改双列叶子（名称省略号 + 大小右对齐、行高统一 26.75px）；`tree-body{overflow-x:hidden}` 消掉横向滚动条（`scrollWidth == clientWidth`）。

## 可复用约定：新增查看页时照做

1. 若是 `<main class="layout ...">` 全屏布局，务必覆盖全局 `main` 的 `max-width/margin/padding`，否则整页被推到中间。
2. 目录树一律按「分组节点 + `.tree-children` 子容器」渲染，从一开始就带折叠状态，避免后补。
3. 需要可调宽度时接 `--tree-w` 三列栅格 + `.splitter` + localStorage 持久化，不要写死像素或用 JS 重排两栏。
4. 折叠、拖拽这类交互验收用几何量（`asideLeft`、列宽、可见叶子数）与计数差，而不是只截一张图。
5. 改完 `static/*.css|js` 需在浏览器强制刷新（`Ctrl/Cmd+Shift+R`）验证，且 `style.css` 要同步三仓。
